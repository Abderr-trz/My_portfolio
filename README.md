# Creative portfolio

Next.js portfolio with five project pages and a React Three Fiber gallery. Run `npm install`, then `npm run dev`. Run `npm run build` and `npm run lint` for production checks.

The spatial gallery is enabled on desktop when WebGL and full motion are available. The project grid remains available on smaller screens, with reduced motion, and when WebGL is unavailable. The gallery also has a text-based project index for keyboard navigation.

Project images are screenshots of the live websites. The capture scripts are included to make refreshing them repeatable.

Before publishing, add confirmed contact details and a canonical domain. The current gallery changes layout using the view controls; a scroll-pinned transition, richer project case studies, and comprehensive accessibility and Lighthouse audits remain to be completed.
