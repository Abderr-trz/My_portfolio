# Creative portfolio

Next.js portfolio with five project pages and a scroll-driven project sequence. Run `npm install`, then `npm run dev`. Run `npm run build` and `npm run lint` for production checks.

On Windows PowerShell, use `npm.cmd install` and `npm.cmd run dev` if script execution policies prevent `npm.ps1` from running. Open `http://localhost:3000`. For a production preview use `npm.cmd run build` followed by `npm.cmd run start`.

The spatial sequence runs on desktop with full motion. A static project grid remains available on smaller screens and with reduced motion. Project previews are keyboard-accessible links.

Project images are screenshots of the live websites. The capture scripts are included to make refreshing them repeatable.
